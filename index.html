Installation & Setup

Follow these quick steps to get ScatterFlow installed and running in your Blender environment.

Setup Steps

1️⃣

Download

Download the latest `.zip` release file from your purchase platform. Do not extract the zip file. Blender will handle the extraction process automatically during installation.

2️⃣

Install

Open Blender and navigate to Edit > Preferences > Add-ons. Click the "Install..." button at the top right, locate your downloaded `.zip` file, and select it.

3️⃣

Activate

Once installed, check the empty box next to "ScatterFlow" in the add-ons list to enable it. You can now access the add-on panels from the 3D Viewport N-Panel.
